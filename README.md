# かいて！モンスターバトル

からだ・うで・あし を 1 本ずつ描くと、モンスターが歩いてパンチで戦う（自動）。足は回って歩き、腕は前後に振る。強く殴られると転ぶ。HP 0 で KO。
CPU モンスター 5 体と勝ち抜き。自分のモンスターを URL（`#r=`）で友達に送ると、友達がそのモンスターと戦える。1 戦 最大 30 秒。

https://renmy-stack.github.io/draw-robot/

## ファイル
- `sim.js` — モンスターの組み立て（肩・腰の位置、重さ・重心）とバトルの物理。土台はドローカーの物理。決定的・DOM 非依存（Node でも動く）。数値を変えたら `SIM_VERSION` を上げる
- `game.js` — 描く画面（からだ → うで → あし）・バトルの描画（2 体に寄るカメラ）・勝ち抜き・モンスターを送る
- `test_sim.js` — CPU モンスターの総当たり、決定的か、URL の往復
- `trace.js A B` — CPU モンスターどうしの 1 戦を 1 秒ごとに
- `test_exploit.js` — ずるい形（ちび体＋長い腕 など）が CPU・ふつうのモンスターにどれだけ勝つか
- `clear_rate.js [体数]` — 人が描きそうなランダムなモンスターで 勝ち抜きの何人抜きの分布（5 人抜き ≈ 10.8%）
- `tune_cpu.js [体数]` — CPU 5 体の 体・腕・足の倍率を、勝ち上がってきたモンスターの 90/80/65/50/40% が勝つように探す（結果は `_cpu.json`）
- `sweep.js` / `tune.js` — 腕の長さ・体の大きさ・足の長さ別の勝率。`tune.js` はつまみ `K` を探す（`node tune.js 16 '{"lenP":[1.2,1.5]}'`）

## 損得のしくみ（v0.5）
- 体が大きいほど HP が多い（面積^0.8、35〜250）。重いほどパンチが重く、ふっとびにくい
- 腕が長いほど 大振り（1 往復 = 0.3 + 長さ×0.007 秒）で 1 発が軽い（×(60/長さ)^1.5）。腕は相手の体をすり抜ける（壁にならない）
- 腕は相手の体を狙って振る（背の低いモンスターにも当たる）
- `tools/icon.html` — アイコン

## 確認
`python -m http.server 8096` → `http://127.0.0.1:8096/_frame.html?shot=5&stage=2`（`&result` で結果、`?draw` で描く画面）。
スクリプトを変えたら `game.js` の `VERSION`・`version.txt`・`index.html` の `?v=` を一緒に上げる。
